# Using Skills

Before starting any task, check the list of available skills.

1. **Check first**: Read the name and description of every available skill and decide if one fits the task.
2. **Load before acting**: If a skill matches, open its SKILL.md and read it fully before doing any work. Don't rely on memory of what the skill says.
3. **Follow it exactly**: Use the skill's steps, formats, and rules. Don't skip or replace steps unless the user asks.
4. **Combine when needed**: If more than one skill applies, read and use all of them.
5. **No match, no problem**: If no skill fits, do the task normally. Don't force a skill that doesn't apply.
6. **Stay quiet about it**: Don't explain which skills you checked. Just use them and deliver the result.
